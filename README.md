# FinTrack – Personal Finance Manager

## Overview
FinTrack is a full-stack personal finance management application designed to help users track income, expenses, budgets and savings.

## Technology Stack
- Frontend: Angular, Angular Material, Bootstrap
- Backend: Node.js, Express, TypeScript
- Database: PostgreSQL
- ORM: Prisma
- Authentication: JWT
- Charts: Chart.js

## Planned Features
- User registration and authentication
- Income and expense tracking
- Category management
- Financial dashboard
- Monthly reports and analytics
- Budget tracking

## Architecture
Modular monolithic architecture with a REST API backend.
